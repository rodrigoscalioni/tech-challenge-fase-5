# Apresentação e entrega

Aqui serão documentados o roteiro executivo, capturas de tela sem dados individuais, evidências de validação, apresentação final e roteiro de vídeo de até 5 minutos.

Os artefatos finais serão adicionados após a validação do pipeline, dashboard e Genie.

## Revisão editorial final do GitHub (Marco 8)

Depois de **concluir todas as etapas de desenvolvimento e a entrega funcional**, realizar uma revisão geral para que o repositório seja apresentado como **um produto analítico contínuo**, e não como uma sequência de entregas isoladas.

Checklist dessa revisão:

- README principal começando pelo problema de negócio, solução final, arquitetura, resultados e demonstração, sem priorizar a cronologia dos marcos;
- instruções de execução end-to-end (fonte autorizada → preparação → Bronze → Silver → Gold → Dashboard/Genie);
- navegação simples com links válidos e estrutura coerente de pastas;
- documentação técnica e decisões importantes acessíveis em uma seção de referência, preservando rastreabilidade;
- remoção de placeholders e artefatos temporários que não agreguem ao leitor;
- validação dos links, imagens, comandos de execução e arquivos da entrega;
- checagem final de privacidade e ausência de dados individuais/credenciais;
- alinhamento dos textos e capturas com a apresentação executiva e o vídeo.

**Importante:** reorganizar a apresentação do projeto não significa reescrever ou apagar automaticamente o histórico de commits. O desenvolvimento continua documentado no Git; a experiência de leitura final será contínua.
